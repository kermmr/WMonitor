# 03 · 视觉规格

所有数值以 **96 DPI** 为基准，代码里统一乘 `k = DeviceDpi / 96f`。
字体族 `Segoe UI`（中文自动回退微软雅黑）。数字全部走 GDI+ `DrawString` + `AntiAlias`。

### 尺寸

| 项 | 值 |
|---|---|
| 高度 | 30 |
| 圆角 | 7 |
| 水平内边距 | 10 |

### 布局（数字条 / 迷你柱）

```
┌ 10 ───────────────────────────────────────────── 10 ┐
│ ● CPU 23 %  │  ● RAM 41 %  │  ● GPU 67 %  │ ...    │  高 30
└────────────────────────────────────────────────────┘
  ↑5↑   ↑4↑ ↑2↑
 dot  label value unit
```

| 元素 | 规格 |
|---|---|
| 圆点 | 直径 5，颜色 = 指标色 |
| 圆点 → 标签 | 5 |
| 标签 | 8.5 px Bold，颜色 = 指标色 @ 65% alpha |
| 标签 → 数值 | 4 |
| 数值 | 12 px Bold，颜色 `Text` |
| 数值盒宽 | `max(实际宽, "88" 的宽)`；带小数的用 `"88.8"` |
| 数值 → 单位 | 2 |
| 单位 | 9 px Regular，颜色 `Label` |
| 项间分隔 | 竖线 1 px × 12 高，颜色 `Sep`，左右各 8（合计 16） |

数值右对齐到固定盒宽 —— 这样 `7%` → `12%` 变化时整条贴片宽度不跳。

### 迷你柱（Bars）

- 位置：数值 + 单位之后，前置间隔 7
- 5 根，宽 3，间距 2，最大高 14，底部对齐 `cy + 6.5`
- 高度 = `max(1.5, pct/100 * 14)`
- 颜色 = 指标色（不透明）
- 只有 `Bar == true` 的项（CPU/RAM/GPU/VRAM）有柱子；网速/温度没有

### 四环（Rings）

| 项 | 值 |
|---|---|
| 环直径 | 26 |
| 环宽 | 3，圆头端点 |
| 环间距 | 8 |
| 外框内边距 | 10 |
| 起点角度 | -90°（12 点方向） |
| 底环颜色 | `Track` |
| 只显示 | `Bar == true` 的项（CPU/RAM/GPU/VRAM） |

| 进度条 | 高 3，圆角 1.5，y = cy + 5 |
| 曲线区 | 92 × 24，右边界 = `right - 66 - 100` |
| 数值 | 15 px Bold，右对齐 |
| 单位 | 9 px，`Label` |
| 底部线 | y = `38 + 52 × 行数 + 4`（4 行 250 / 5 行 302） |
| 底部文字 | 9.5 px，y = 底部线 + 12 |
| 齿轮 / 关闭 | 18 × 18 圆，右侧，间距 30 |

**曲线**：固定 60 点，线 1.5 px @ 65% alpha，填充 13% alpha，`pct/100` 映射到高度。
数据源：历史开启时来自 `HistoryStore.Query`（每桶取最大值），关闭时退回 60 点实时缓冲。

**时间窗**：历史总开关关闭时不画小段，改显示 `1s · 60 点` 文字说明（三个窗口共用同一份缓冲，给分段是骗人）。
未开「跨重启保留」时不画 `24h`（没有数据源）。

**磁盘行**：`磁盘  读 159K · 写 559K    ▁▂▅▃   638K /s`，曲线按对数刻度归一（20 KB/s ≈ 26%，100 MB/s 满）。

**告警着色**：`AlertView.Firing` 命中的指标整格变 `Alert` 色（圆点、标签、数值、迷你柱一起变）。

**关闭行为**：`Deactivate` → `Hide()`；打开后 350 ms 内忽略（防焦点抖动）。

## 4. 托盘图标

基准 16 px，实际用 `SystemInformation.SmallIconSize`（高 DPI 下 20/24/32）。

**渲染管线（v0.04 起）**：所有样式先按 4 倍尺寸画到 64×64 位图，再用 `HighQualityBicubic`
缩到目标尺寸，最后 `BoostAlpha(1.35)` 把半透明边缘往实色推。
16 px 下直接画字笔画粗细不匀、边缘发灰，超采样后明显干净。
对比图：`WMonitor.exe --icons` → `D:/Hermes/output/results/wmonitor-icons.png`。

| 样式 | 画法 |
|---|---|
| 双数字 | 上排主指标、下排次指标，字号 `0.58 × size`（16 px → 9.3 px Bold），行中心在 0.25 / 0.75 高度，无分隔线 |
| 双环 | 外环主指标（内缩 `0.09 × size`），内环次指标（= 外环 × 0.56），环宽 `0.125 × size` |
| 四段条 | 4 条水平条，高 `0.16 × size`，间距 `0.055 × size`，宽 = `size - 2 × 0.09 × size` |
| 单指标 | 主指标大数字 `0.80 × size` Bold（中心 0.36 高度）+ 底部 `0.11 × size` 进度条 |

**指标槽位**：`AppConfig.TraySlots` 按样式给 1/2/2/4 个槽位，分别取
`TrayPrimary / TraySecondary / TrayThird / TrayFourth`（枚举 `TrayMetric`：CPU、内存、GPU、显存、网速、温度）。

**文字自适应**：`FitFont` 逐次 ×0.9 缩字号，保证 `100`、`12M` 这类宽字不越界。

**非百分比指标的量程**：

| 指标 | 文字 | 环/条填充 |
|---|---|---|
| 网速 | 下行速度 `0 / 345K / 12M` | 对数刻度：20 KB/s ≈ 26%，1 MB/s ≈ 60%，100 MB/s 满 |
| 温度 | 整数摄氏度 | 30 °C 起、100 °C 满 |

颜色沿用指标色；底色透明（`GetHicon` 保留 alpha）。图标每秒最多重建一次（`TrayIconRenderer.Key` 变了才重画）。

## 5. 设置窗口（v0.11 Bento 面板）

| 项 | 值 |
|---|---|
| 窗口 | **1238 宽 × 自适应高度**（约 850），固定边框，居中，置顶，无图标 |
| 网格 | 4 列 × 3 行，`Pad = 24`、`Gap = 14`、`ColW = 287`（`(1238 − 48 − 42) / 4`） |
| 卡片 | 圆角 14，内边距左右 18 / 标题区 50 / 底部 18；底色 `CardBg`，1 px `CardBorder` |
| 标题栏 | 深色（`DwmSetWindowAttribute` 20 / 19）；顶栏 64 高，底栏 56 高，都不进网格 |
| 滚动 | 正常配置下**不出现滚动条**；只有内容超过工作区高才由 `Panel(AutoScroll)` 兜底 |
| 分段控件 | 高 34，圆角 8，选中块圆角 6 |
| 胶囊开关 | 高 30，圆角 15，文字两侧各 15 |
| 步进框 `Stepper` | 78~84 × 30，圆角 8，− 值 +，两侧按钮区各 26 宽，按住连续步进（380 ms 后 55 ms 一步） |
| 按钮 `BentoButton` | 视觉 34 高（告警卡内 30），圆角 10 / 9，**无描边**；主按钮 `#0A84FF` 白字 Bold，次按钮 `Soft` + `Text` 色 |

**卡片网格**（跨列数决定宽度，行高 = 该行最高卡片）：

```
┌──────────────────────┬──────────┬──────────┐
│ 贴片 (跨2)           │ 外观     │ 显示项   │   行0
├──────────────────────┼──────────┼──────────┤
│ 托盘图标 (跨2)       │ 历史记录 │ 行为     │   行1
├──────────────────────┴──────────┴──────────┤
│ 告警 (跨4)                                 │   行2
└────────────────────────────────────────────┘
```

卡片内容：

| 卡片 | 内容 | 备注 |
|---|---|---|
| 贴片 | 位置 / 风格（同一行两栏）、所在屏幕 / 水平微调（同一行，单屏时微调自动左移）、底部一行操作提示 | 屏幕行只在多屏时出现 |
| 外观 | 主题、刷新间隔、不透明度（滑块 + 数值） | |
| 显示项 | 7 个 chip 两列排（CPU / 内存 / GPU / 显存 / 网速 / GPU 温度 / 磁盘 IO） | |
| 托盘图标 | 图标样式 + 主 / 次 /（四段条）第三 / 第四指标，行内标题 76 宽、控件占满余下宽度。**每种样式各存一套槽位**（`AppConfig.TrayFor(style)`），切样式时行内值跟着换 | 次指标在「单指标」下隐藏 |
| 历史记录 | 记录历史 + 跨重启保留、保留时长、面板默认时间窗、占用提示；关历史时显示一行说明 | 保留时长要开持久化 |
| 行为 | 5 个整宽开关竖排：显示贴片 / 锁定位置 / 点击穿透 / 始终置顶 / 开机自动启动 | |
| 告警 | 一行：启用 + 4 个动作 chip + 选择脚本…；下面 5 列规则，每列「指标 chip / 阈值 % / 持续 秒」 | 关告警时只留启用 + 一句说明 |

**布局模型**：每张卡维护 `List<Row>`（行高 `H` + 显示条件 `Show` + 若干 `Cell(C, X, Y, W, H, Show, XOf)`），
`LayoutCards()` 分三步：① 算各卡自然内容高；② 网格行高取该行最大；③ 摆卡片，并把多出来的高度
**按行间 28 px 上限**摊掉（内容贴顶，不整块飘到底部）。`Cell.XOf` 用于「同一行里跟条件控件换位」
（单屏时水平微调左移）。加设置项只需 `AddRow`，不用碰窗口尺寸。

**按钮交互**（`UI/Bento.cs` 的 `BentoButton`，实现 `IButtonControl`，可当 `AcceptButton`）：

| 状态 | 表现 |
|---|---|
| 常态 | 圆角实心，无描边；主按钮蓝底白字，次按钮 `Soft` 底 + `Text` 色字 |
| hover | 底色提亮（主按钮混 20% 白、次按钮混 14% 白），投影抬高 4 px、8 层渐隐（主按钮用主色调暗的蓝影） |
| 按下 | 底色压暗（主按钮混 24% 黑），文字下沉 1.5 px，投影收起 |

控件高度 = 视觉高度 + 6（告警卡内 +8），多出来的几像素是留给投影的，否则会被控件边界裁掉。

## 6. 动效

没有动画。所有状态变化都是 1 秒内的重绘，加过渡反而显得卡。
唯一的时间相关行为是面板的 350 ms 防抖窗口。
