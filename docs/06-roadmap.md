# 06 · 路线图

按"用户价值 / 实现成本"排序，`P0` 是下一步就该做的。

> **v0.05 的完整施工图在 [`08-dev-plan-v005.md`](08-dev-plan-v005.md)**（多屏贴片 / 磁盘 IO / 历史曲线 / 阈值告警），
> 本文只保留还没进入施工阶段的条目。

## P0 · 补齐现有功能的短板

- [ ] **副屏任务栏支持** —— 枚举 `Shell_SecondaryTrayWnd`，每块屏一个贴片（或设置里选屏）。
  目前只贴 `Shell_TrayWnd`（主屏）。**→ 已进入 v0.05 施工（`08-dev-plan-v005.md` §3）**
- [ ] **多卡切换** —— `cfg.LockedGpuLuid` 已支持锁定，但设置界面没暴露。加一个"监视哪块 GPU"下拉。
- [ ] **开机自启的路径修正** —— 用户移动安装目录后，注册表里还是旧路径。启动时检测并自动更新。
- [ ] **单实例唤起** —— 重复启动时把已有实例的设置窗口叫到前台，而不是静默退出。

## P1 · 体验增强

- [ ] **面板里显示 Top N 进程**（按 CPU / GPU / 显存排序）—— 需要 `GPU Engine` 的 pid 分组，注意别把采样开销带回来（可以只在面板打开时采样）。
- [ ] **网速分接口** —— 现在是把所有物理网卡加总；改成可选单接口（有线/无线分开）。
- [ ] **磁盘 IO**（读写速率）—— PDH `\PhysicalDisk(_Total)\Disk Read/Write Bytes/sec`，成本低。
- [ ] **告警**：CPU / GPU 温度或占用超阈值时，贴片数字变红或托盘图标闪一下。
- [x] **贴片可拖动** —— v0.04 已实现（按住拖动、落在任务栏吸附、写回 `FreeX/FreeY`）。
  剩余只有「位置锁定 / 点击穿透」，见 `08-dev-plan-v005.md` §4。
- [ ] **点击穿透模式** —— 贴片不响应鼠标（纯展示），避免误点。

## P2 · 工程化

- [ ] **安装程序**（Inno Setup 或 MSIX）—— 目前"安装版"是手动 publish 到目录。
- [ ] **自动更新** —— 检查 GitHub Release / 自建 URL，下载新 exe 后替换（需要处理运行中替换）。
- [ ] **单元测试** —— 目前 0 测试。可测的纯逻辑：`NormalizeInstance`、`NetFmt`、`ValueBox` 宽度、`TryAnchor` 的坐标计算（把 Win32 调用抽成接口）。
- [ ] **CI** —— GitHub Actions：`windows-latest` 上 build + 打两个 artifact。
- [ ] **崩溃上报** —— 现在只写本地 `error.log`。

## P3 · 可选

- [ ] 托盘图标单色模式（部分主题/第三方托盘对彩色图标不友好）
- [ ] 多语言（en / zh-CN）
- [ ] 主题自定义（强调色、贴片透明度）
- [ ] 图表时间窗切换（60 秒 / 5 分钟 / 15 分钟）
- [ ] 便携模式（配置写在 exe 同目录的 `config.json`，不写 `%APPDATA%`）

---

## 明确不做

- ❌ 真正的任务栏嵌入（Win11 不允许）
- ❌ 硬件级监控（风扇转速 / 电压 / 主板温度）—— 需要内核驱动或 LibreHardwareMonitor，破坏"零依赖"和"零权限"的前提
- ❌ 远程监控 / 云同步
- ❌ 游戏内 Overlay
